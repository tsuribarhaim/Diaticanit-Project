# Personal Health Companion

## Project Goal
A personal assistant project focused on health tracking, guidance, and actionable insights.

## Folder Structure
- `docs/requirements/`: Requirement documents and product expectations.
- `docs/design/`: Architecture, UX, and technical design documents.
- `src/`: Application source code.
- `tests/`: Test cases and test utilities.
- `data/`: Sample and local data files.
